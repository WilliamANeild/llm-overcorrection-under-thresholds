# Project exemptions to the global voice rules

## "the revision gate" — approved coined term, 2026-09-20

`writing-voice-core.md` hard-blocks "gate" and a hook enforces it. That ban exists because
"gate" is usually a dead metaphor for *threshold* or *screen*. The same file exempts "terms
coined in the user's own work".

"The revision gate" is such a term. It names the binary point at which a model decides to
revise or not, it is used at all twelve occurrences for that one construct, and Study 1's
finding is that the decision is bimodal rather than graded, which is what makes a gate the
accurate figure rather than a reach. The suggested replacements read worse here: "screen"
loses the pass or no-pass sense, and "threshold" collides with the sufficiency threshold,
which is a different quantity in this paper.

Decision: keep it. Liam may want to add "the revision gate" to the coined-term exemption list
in his global `writing-voice-core.md` so the hook stops blocking edits to these sections.
